# PRD — Product Requirements

## MVP Goal
Allow a founder to manage companies and company administrators, and allow an authorized company user to create and manage PostgreSQL table structures.

## Super Admin
Login, dashboard, create/view/edit companies, activate/suspend companies, manage company administrators, view basic audit activity.

## Company Panel
Login, company dashboard/workspace, create workspace/schema if required, create/list/view/rename/delete tables, view structure, add/rename/delete columns, change supported data types, reorder columns, configure basic constraints.

## Explicitly out of scope
Data entry, spreadsheet/grid UI, collaboration, real-time editing, data modelling, relationships, CSV/XLSX import/export, BI connectors, external DB connections, public APIs, AI, billing, advanced roles, analytics, workflows and mobile.

## Success
A founder can create a company and administrator. A company user can safely manage its table structures. Cross-company access is rejected and audited.
